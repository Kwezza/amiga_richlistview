# Historical / mixed-era planning documents

These documents were copied from the source `amiga_custom_listview` repository
during RichListview extraction. They discuss both the legacy GadTools
`LISTVIEW_KIND` enhancement and the full custom control.

They remain useful for design history, but they are **not** authoritative
RichListview architecture docs. Prefer `docs/audit/` and the current
`src/rich_listview/` sources for product decisions.
